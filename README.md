# 🌱 Habit Tracker

A simple and elegant **Habit Tracker App** that helps you build consistency, track your goals, and maintain streaks.  
Built with **HTML, CSS, and JavaScript**, this app saves your progress in **local storage**, so your habits stay even after refreshing the page.

## ✨ Features
- ✅ Add new habits with name, description, and duration  
- ✅ Track total habits, completed habits, and active streaks  
- ✅ Edit or delete existing habits  
- ✅ Mark habits as completed each day  
- ✅ Automatic streak tracking  
- ✅ Local storage support (no database required)  
- ✅ Clean, minimal, and responsive design
